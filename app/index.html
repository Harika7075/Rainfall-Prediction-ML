How this works: a Decision Tree was trained on the project's weather dataset (humidity, temperature, pressure, wind and location features) to classify whether a day had measurable rainfall. The tree's learned rules were exported straight into the JavaScript running on this page, so no server or API call is needed — everything above runs locally in your browser. Test-set accuracy for this tree: 76.1%. Year and wet-bulb temperature (barely used by the tree) are held at typical dataset values for simplicity.
