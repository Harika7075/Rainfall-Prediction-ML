How this works: a Decision Tree was trained on the project's weather dataset (humidity, temperature, pressure, wind and location) to classify whether a day had measurable rainfall. It uses plain latitude/longitude rather than a fixed list of district names, so it works for any place — type a name above and click Find (needs internet access in your own browser), or enter coordinates by hand. The tree's rules run directly as JavaScript on this page — no server needed for the prediction itself. Test-set accuracy: 76.1%. Year and wet-bulb temperature (negligible importance) are held at typical dataset values for simplicity.
